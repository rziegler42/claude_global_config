# Specifications

This directory holds durable, repository-owned requirements and behavioral
specifications. Specifications describe the intended outcome and acceptance
criteria; implementation sequencing belongs in `../plans/`, and durable design
choices belong in `../decisions/`.

Use concise, descriptive lowercase kebab-case filenames, for example:

```text
docs/specs/enclosure-fit-and-clearance.md
docs/specs/printable-latch-requirements.md
```

Each specification should identify its scope, non-goals, assumptions, relevant
constraints or interfaces, acceptance criteria, and links to governing drawings,
ADRs, or external requirements. Update it when the intended behavior changes;
do not use it as a chronological work log.
